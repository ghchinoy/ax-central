# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-11-01

### Added
- Initial Wails v2 + Lit 3 WebComponents (`<ax-central>`) desktop app with Luminous 0.15–0.19 light/dark design tokens.
- Activity (`<ax-overview>`), Map (`<ax-topology>`), Deploy (`<ax-designer>`), Terminal (`<ax-terminal>`), and Clusters (`<ax-clusters>`) views.
- First-class macOS Apple `container` (`ate-local`) stack management, `~/projects/ax-experiments` templates (`ate-local`, `genkit-apple-container`, `swarm-reviewer`), and `hack/doctor.sh` prerequisite auditor & bootstrap installer.
- WebMCP `ToolHost` (`document.modelContext` + fallback registry) and `<ax-webmcp-drawer>` exposing 16 AX tools.
